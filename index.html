      📚 Base de plats

      Cet outil est 1 seul fichier HTML. Tes ajouts/modifs sont sauvegardés automatiquement dans le navigateur, et un fichier de sauvegarde JSON est aussi téléchargé automatiquement (base-plats-neuils-backup.json) à chaque changement, pour ne jamais rien perdre. Pour transférer ta base sur un autre appareil, utilise l'export/import ci-dessous.

      Si tu choisis un dossier (ex. ton dossier OneDrive synchronisé), les sauvegardes automatiques seront écrites directement dedans (fichier base-plats-neuils-backup.json, écrasé à chaque modification — pas de téléchargement multiple). OneDrive synchronisera ce fichier automatiquement.
      ⚠️ Fonctionne uniquement sur Chrome / Edge (PC). Le dossier doit être re-sélectionné si tu changes de navigateur ou d'ordinateur.


      Format JSON attendu : une liste d'objets {"nom": "Nom du plat", "saison": "ete|hiver|toutes"}.
      L'import remplace entièrement la base actuelle (donc exporte avant si tu veux garder une copie).
